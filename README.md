# 📧 Email Spam Classifier (SVM)

A machine learning project that classifies text emails into **Spam** or **Not Spam (Ham)** using `scikit-learn`'s **Support Vector Classifier (SVC)** and **CountVectorizer** for text tokenization and numerical representation.

---

## 🚀 Features

- **Text Vectorization**: Converts raw text emails into numerical word-frequency feature vectors using `CountVectorizer`.
- **Support Vector Machine**: Trains a linear kernel `SVC` model to construct an optimal decision boundary between spam and non-spam messages.
- **Inference Pipeline**: Accepts new, unseen email strings and predicts their category in real time.

---

## 🛠 Tech Stack

- **Language**: Python 3.x
- **Machine Learning**: `scikit-learn` (`SVC`, `CountVectorizer`)
- **Data Processing**: `numpy`
